# ECPRO Radar — WordPress 外掛

在 WordPress／WooCommerce 網站顯示 ECPRO 電商力徽章與技術偵測結果。

- 短代碼：`[ecpro_badge]`（電商力徽章）、`[ecpro_detect]`（技術偵測卡）
- 後台儀表板小工具：你的網站在 ECPRO 資料庫的體質摘要
- 安裝：把 `ecpro-radar.php` 放進 `wp-content/plugins/ecpro-radar/` 後啟用

資料來源：[ECPRO 電商博士](https://ecpro.tw)（台灣 13 萬+ 網站實測資料庫）。相關：[台灣商品比價](https://ecpro.tw/price/)、[MCP server](https://github.com/kewelin/ecpro-mcp)。MIT License.

## English

# ECPRO Radar — WordPress Plugin

Display the ECPRO e-commerce strength badge and technology detection results on your WordPress / WooCommerce site.

- Shortcodes: `[ecpro_badge]` (e-commerce strength badge), `[ecpro_detect]` (technology detection card)
- Admin dashboard widget: a summary of your site's profile in the ECPRO database
- Installation: place `ecpro-radar.php` into `wp-content/plugins/ecpro-radar/` and activate it

Data source: [ECPRO 電商博士](https://ecpro.tw) (a measured database of 130,000+ Taiwanese websites). Related: [台灣商品比價](https://ecpro.tw/price/), [MCP server](https://github.com/kewelin/ecpro-mcp). MIT License.
